# Fire Globe

A web app for the NASA Space Apps Challenge 2026, **Harmonization of MODIS and VIIRS Hot
Spots**. Spin a satellite globe, select an area (a rectangle or a whole country) and a date
range, and get a harmonized burning-activity calendar from 2000 to today, with charts,
anomalies and CSV/PNG downloads.

How everything works, step by step and in plain words: [HOW_IT_WORKS.md](HOW_IT_WORKS.md).

## Use it

| Action | How |
|---|---|
| Spin / zoom | Drag / scroll |
| Select a rectangle | Hold **Shift** and drag, or press **Select** and drag |
| Select a whole country | **Shift + click** on it |
| Deselect | Click anywhere outside the selection, or **Clear** |
| Choose dates | From / To (month and year), or **Last 12 months** / **All** |
| Monthly fire map | Bottom-left bar: drag the month cursor, type a year |
| Downloads | Monthly table (CSV), every hotspot in the search (CSV), charts (PNG) |

## Run it on your computer

```bash
python3 tools/serve.py          # then open http://localhost:8765
```

`serve.py` is a small static server that supports partial file downloads, which the app
uses to read pieces of the large data files. Python's built-in server does not.

## Folder layout

```
index.html, app.js      the web page and all of its code
vendor/                 MapLibre GL JS (globe engine), stored locally
geo/countries.json      country borders (Natural Earth, public domain)
data/                   NOT in git (too big); everything below is regenerated by tools/
  raw/world/            NASA FIRMS CSVs: keep them, they are the source for every rebuild
  meta.json, coarse.bin, blocks/, tiles/, heat0/, heat1/   converted data the app reads
tools/
  build_world.py        converts data/raw/world into data/ (about 45 minutes)
  fetch_nrt_world.py    downloads the current year from the FIRMS API (about 1 hour)
  serve.py              local server
  publish_to_team.sh    copies the app to the team GitHub branch (webapp/ folder) and pushes
  deploy.sh             publishes the public website on Cloudflare Pages
  countries_50m.geojson outline used to keep only on-land detections from the API
  legacy/               first Argentina-only versions, kept for reference
```

## Update the data

```bash
# 1. New days of the current year (needs your FIRMS key in .firms_key; resumes where it stopped)
python3 -I tools/fetch_nrt_world.py data/raw/world/nrt_2026 2026

# 2. Rebuild the converted data (writes to data/_build, then swaps it in)
python3 tools/build_world.py data/raw/world data/_build World \
  && rm -rf data/tiles data/blocks data/heat0 data/heat1 data/coarse.bin data/meta.json \
  && mv data/_build/* data/ && rmdir data/_build

# 3. Share it
tools/publish_to_team.sh "What changed"     # code to GitHub
tools/deploy.sh                             # code + data to the public website
```

When a new year's archive comes out, add its folders to `data/raw/world/` and rebuild.
The free FIRMS key is requested at https://firms.modaps.eosdis.nasa.gov/api/map_key/ and
saved in `.firms_key` (never committed, never printed).
